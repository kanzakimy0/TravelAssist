# Personal Center runtime media

Owned by B / Personal Center.

## WBS 5.1

- `sidebar-torii-watercolor.svg` — decorative Sidebar artwork.
- `personal-center-surface-texture.svg` — low-contrast Personal Content Area surface texture.

### Sidebar artwork

Use the torii SVG inside the existing cropped Sidebar artwork container. It is decorative and should use empty alt text / `aria-hidden` semantics.

### Main content surface texture

Use `personal-center-surface-texture.svg` as a subtle background layer for the Personal Center content surface. It freezes the approved 1.21 / 1.22 direction: warm ivory, very faint washi grain, soft sakura-pink watercolor haze, restrained petals, a small low-contrast seigaiha area and sparse warm-gold dust.

Do not enlarge or reposition its decorative details into a focal illustration.

## Code-driven visuals

Do not add navigation icons, notification, chevrons, buttons, active / hover / focus states, avatar UI, cards, borders, shadows or radius as raster assets. Those remain component / inline SVG / CSS / Design Token driven.

Travel photos shown in the WBS 5.1 mock home remain content fixtures and are not frozen as WBS 5.1 Shell assets.
