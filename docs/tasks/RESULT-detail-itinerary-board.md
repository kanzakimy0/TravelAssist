## Status

本地实现与验证完成；3113 已更新。未 commit / push / merge，未改变既有 Issue / PR 状态。

## Implemented

- 详情页取消时间比例和上下交错布局。所有项目置于轴线下方，顺序等距、等宽。
- 每列三张同尺寸圆角方卡：时间 / 持续时间 / 行程名；本地状态与提醒；预约管理或大加号。保留绿 ✓、黄 !、红 × 和完整说明。
- 提醒卡提供详情 / 调整、稍后核对及加号菜单：阅读、完成、锁定、地图定位、管理预约。阅读不消除原风险，稍后处理不会改变预约时间。
- 预约状态区分未加入、待预约、已选渠道、手动已确认、已取消记录；加入列表不代表已下单。确认前需要明确勾选已在渠道完成。
- 已确认项目可准备联系消息，模板与手动内容可复制或保留草稿，不会发送。取消入口要求确认已在原渠道取消，仅更新本地记录，原锁定仍保留。
- 酒店替换使用当前目录，不伪造查询。已确认 / 锁定住宿受保护；渠道取消已记录后，明确选用新酒店才替换，保留日期晚数，清除旧渠道、消息和完成状态，新酒店不视为已预约。
- 无来源的自定义项目不伪造预约渠道，可先记录联系消息 / 待核对事项。
- 提醒响应和消息草稿纳入现有显式浏览器保存；刷新恢复、放弃修改与并发保护沿用原机制，无第二套持久化记录。
- 仅 Detail 展开行程栏加高；手机近全屏面板，横向浏览项目列。保存 / 返回 / 新增位置及最小化操作条保留。Detail 矮地图区域工具栏紧凑横排，避免工具被裁切。Planner 25dvh 底栏与景点时间轴不改。
