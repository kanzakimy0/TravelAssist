# Detail 状态、总览与新增项目定位修正

## 完成内容

- 餐饮默认显示三条完整操作行；住宿占餐饮组高度的 1/3。选择、更换和加入预约直接可用，不再替换成无按钮摘要。
- 顶部四张卡使用更明显的绿、黄、红、蓝背景、描边、数字和状态符号。
- 下层待补充/预约卡使用蓝色背景；已预约的下层预约卡隐藏，真实行程项目与右侧预约记录保留。
- 需确认卡的操作统一为等宽“同意 / 无视”。无视只记录稍后处理，不掩盖实际冲突。
- 收起行程按钮位于日期选择栏最左边，包含手机布局。
- 总览按时间排列所有项目，包含三餐、住宿和未安排槽位。未确定的三餐仅用默认时间排序，界面不冒充已确定时间。
- 总览颜色反映冲突、需确认、待补充/预约和正常；右栏复用单日布局，汇总全程问题、预约待办和已知费用，并支持切换每天餐宿。
- 所有卡片切换复用同一个“项目详情框”，清理旧编辑/新增状态，支持详情打开时继续选择其他项目；修复手机详情遮挡右栏入口。
- 新增景点/餐饮/酒店等支持匹配现有目录地点，或手动填写有效经纬度。地图标记可选择，位置随显式浏览器保存及刷新恢复。
- 新增项目中的测试工具可主动添加标为“[测试]”的时间重叠项目。双方出现红色感叹号，删除测试项目后重新计算状态，不自动保存测试数据。
