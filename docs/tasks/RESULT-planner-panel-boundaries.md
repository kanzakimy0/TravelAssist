## Implemented

### 最新追加：六选单框向上展开

- 六栏默认收起。点击选单或右下角向上箭头后，仅当前选单向上延伸；扩展内容与按钮等宽、无间隙连接，展开时原标签改为“详细信息”。右下角向下细箭头收回内容并恢复原名称与向上箭头。
- 取消旧独立 330px 小窗外观与额外“展开单日详细”横条。为避免手机横向滚动容器裁切，内部仍使用原 top layer 机制，但视觉边框与选单无缝衔接；不改变下面执行区的尺寸。
- 展示 Dn / 城市、实际景点名称、带解释的指标与保护提醒，增加暖色/灰绿细分隔线；不再只显示数字。保留说明与提醒的进一步展开。
- 当前生产验收：四尺寸 × 六栏，扩展宽度与对应按钮相同（差 <1px）、衔接偏差 ≤2px、默认不自动展开、原名/详细信息切换、折叠往返、下面执行区尺寸完全不变；原独立移动卡和预约边界回归通过。187 tests / lint / typecheck / build 通过。此条覆盖下方早期独立摘要窗规则。

### 追加：紧凑摘要与独立移动卡

- Tab 上方小窗从 450px 缩至最多 330px；默认只显示标题与三项指标，详细解释放入可展开的“说明与提醒”。四尺寸默认高度均不超过 195px。
- 移动栏改为每一段一张独立卡片，卡内内容 / 提示 / 决定上下严格三等分。桌面横向排列，窄屏横向滑动；不改变 25dvh 底栏。
- 每卡默认两个快捷按钮“接受提示 / 忽略提示”与一个加号。加号展开“稍后核对 / 查看出发地点 / 查看抵达地点 / 调整交通偏好 / 到详情核对预约”。每段决定独立，继续沿用原配置与浏览器保存结构。
- 最终生产版四尺寸验证卡片三等分（高度差 <1px）、两快捷按钮与加号、五项更多操作、Esc/焦点恢复、不同卡片状态不串联；六 Tab 与详情入口回归通过，pageerror 为 0。187 tests、lint、typecheck、build 通过；截图含 `*-movement-more.png`。

### 原职责拆分（保留，移动布局以上述追加为准）

- Planner 仅查看、选择和调整推荐，不办理预约。地图区域、地点操作、推荐栏底部与预约 Tab 的入口统一转入详情；酒店/餐厅候选与渠道操作仅 Detail 开放。保留已有酒店与预约锚点的只读信息，不删除用户安排。
- Detail 增加区域候选入口与全部预约管理，继续使用既有本地清单；真实下单、支付、库存和云数据库均未接入。
- 同行人增加独立“老人”计数与说明；纳入人数汇总。旧浏览器存档缺少该字段时补 0，兼容未完成的设置基线，不丢失原数据。
- 更多行程设置使用实际按钮定位，桌面优先在入口左侧相邻展示、窄屏限制在视口内；统一分类编号与暖色卡片。七分类、Draft、取消恢复、应用、重规划影响预览和固定节点保护保留。
- Planner 六 Tab 为行程、移动、预约、备选、住宿·餐饮、旅行体检。进入/切换时显示该 Tab 上方的单日小框，可关闭折叠并重新展开；不同 Tab 展示相应摘要。单日时间轴移除左侧重复摘要，给主要内容让出空间。
- 移动分三段：移动段选择 / 非实时出行提示 / 接受、忽略、稍后核对、查看地点、进入详情核对。选择会保存在工作区配置中，接受提示不会假装已经改动车程或预约时间。
- 预约仅列当前范围内有可用渠道样例的景点、活动、交通待购票项，排除酒店、餐厅与已完成/取消项。库存未知的项目不冒充可购票。实际办理转入详情。
- 备选提供雨天室内、减少体力、避开热门目标；保留预览与确认替换，不替换固定预约、酒店或锁定节点，也不在替换时自动发起预约。
- 住宿餐饮按住宿区域 / 餐饮区域 / 衔接理由三块展示，不列具体酒店餐厅推荐。详情保留既有单日执行轨道、显式浏览器保存和未保存离开保护；本轮六 Tab 重排作用于 Planner，未擅自将详情执行轨道整体换成六 Tab。
