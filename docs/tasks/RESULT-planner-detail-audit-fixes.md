# Planner / Detail 审核建议修正

日期：2026-09-07。范围：用户确认后的两页内容、选项、状态和保存逻辑修正；不是新增 Provider / AI / DB Task。

## 已实现

1. 共用时间校验：拒绝无效、反向、等长时间；编辑失败显示原因。
2. 原行程和手动草稿共同参与重叠检查；固定和锁定项目仍受保护。
3. 预约默认处理当日待办，另设明确的全程入口；保留三秒确认保护。
4. Planner 进入 Detail 使用当前聚焦日期并保留选择。
5. 提醒分别提供调整时间、缓冲预览、替代项目、稍后处理；稍后处理不隐藏问题。
6. 重新检查执行本地规则；调整先预览真实时间变化，取消不修改，保护固定项目，不新增虚假的缓冲行程。
7. 费用展示已估算部分；成年人和老人数量参与估算，酒店、儿童票价等资料不足项显示待估算。
8. 婴儿同行要求至少有成年人或老人。
9. 快捷设置的成员和日期变化纳入待重新规划提示。
10. 执行完成和检查状态分离，可撤销完成，不能用完成掩盖警告。
11. 早餐、午餐、晚餐分别检查缺失；返程日不提示必须安排当晚酒店。
12. 快捷菜单使用草稿，应用后提交；取消、关闭、Esc 放弃本次菜单修改。
13. 四个状态计数补充说明：检查状态互斥，预约状态独立。
14. 住宿保留约四分之一右栏高度，增加日期与状态摘要；预约保留 25dvh；折叠展开不推挤其他区块。
15. 浏览器仅保留一份行程，覆盖其他方案前必须确认；取消不覆盖，刷新恢复，离开保留未保存提示。
16. 修复平板宽度下保存说明换行挤占轨道、遮挡折叠预约按钮的问题；不增加下部栏高度。
