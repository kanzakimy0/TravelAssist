## Implemented

- 上轨包含当天所有行程种类；以最早开始到最晚结束建立六等分刻度，卡片根据开始分钟按比例定位。紧凑卡片保持约 116px 宽，内容多时轨道横向滚动，不增高桌面底栏。
- 下轨备用可拖到上轨两张卡之间，开始时间为前一项结束 +15 分钟；保留时长，不改变其他项目。支持上轨重排、移回下轨，不做空档充足判定。
- 重叠 / 跨午夜不自动挤走其他项目，不静默折回当天；Detail 继续显示冲突。结构性输入上限为每次编辑 1–720 分钟、单轨草案最多七天，不是空档限制。
- 右侧按钮拆为时钟与锁定。时钟附近显示开始时间和持续时间；提供菜单插入 / 移回备用作为触屏、键盘替代。锁定禁止拖动和改时；固定预约 / 已确认预约 / 跨日酒店维持保护。
- 支持鼠标与 pointer 拖动、空格拿起、左右选位置、上下换轨、回车放下、Escape 取消；同开始时间提供卡片轮换按钮，避免后台卡无法点选。
- 补齐离开酒店、早餐、午餐、晚餐、回到酒店槽位。已有对应安排复用；缺失项先进入备用，不因打开页面自动改写计划。未选具体地点明确为占位，不冒充地图 POI、酒店订单或真实餐厅；禁止直接加入预约。
- 时间、锁定、备用及槽位字段进入既有浏览器保存结构；兼容旧快照。Planner 不自动保存，仍从 Detail 保存。
- 增删 / 改时沿用共享状态与相邻交通段失效逻辑，不调用路线 API。
