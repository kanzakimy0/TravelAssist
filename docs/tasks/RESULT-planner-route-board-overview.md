# Planner 方案 / 备用景点、移动段与总览调整

## Status

本地实现与验收完成，待用户审查。保留当前工作区已有修改；本轮未创建 PR、提交、推送或合并。

## Implemented

- 详情的行程总览不再单独显示餐饮、住宿栏；行程建议跨越原有三个栏位，完整接收两栏空间。单日详情餐饮和住宿仍保留，3:1 比例不变。
- 顶部四张状态卡恢复柔和绿、黄、红、蓝配色，数字和状态含义保留；总览建议显示全程而非冒用某一天的摘要。
- Planner 行程改为“上方方案景点 — 中间行程轴 — 下方备用景点”。包括景点与活动，不混入酒店或餐饮节点。
- 景点可移入备用再放回方案，保留原 ID、资料与可用原时间；新加入项目只分配本地空档，不移动已有项目或固定预约。没有足够空档则提示并保持原方案。
- 锁定、固定时间、已确认预约 / 购票及预约处理中的项目不能直接移入备用。
- 备用区复用现有地点目录，不捏造地点和坐标；查看任意候选复用同一个项目详情框与真实目录坐标标记。
- 移动页沿用当天行程顺序，只保留紧凑地点简介，地点间放置交通连接卡；可编辑方式、预计分钟与缓冲，支持取消、应用及接受 / 忽略 / 稍后核对提示。
- 最新视觉微调：移动框改为窄底、长侧边的小圆角竖向长方形，宽度约为高度的 74%，矮屏保留至少 72px 阅读宽度。名称框继续淡色小正方形，约为交通卡半宽并保留至少 44px 点击区域；维持 11px / 500 字重。移除行程组自动拉伸空隙，连接箭头与两侧间距缩小；预计移动和缓冲分两行，完整修改状态移至悬停说明，风险文字始终保留。底栏高度、色彩、数据与编辑操作不变。
- 修改交通不改项目时间；超出空档会标记冲突。实际相邻节点变化后，失效的交通覆盖与旧连接描述会清除。
- 交通状态补充：电车蓝、巴士紫、步行绿、自驾青、出租车米褐、新干线靛紫、渡轮薄荷绿、飞机天蓝、待确定暖灰。问题卡按 135° 对角线一半保留交通色，一半红色 / 黄色；普通卡只显示交通色，保留文字说明而非只靠颜色。
- 红色代表本地时间重叠或预计移动加缓冲超出空档；黄色代表未知方式 / 时长，或剩余余量少于本地 15 分钟检查线。该规则不是实时路况预测，正常底色也不代表服务商已验证。
- 行程与交通共用派生状态。详情时间调整立即重判风险；增删、转入备用、放回及同 ID 更换酒店会清除受影响连接的旧估计，不清空其他连接或其他方案的手动设置。
- 1 日、3 日、全日保留，两个页签复用同一个日期 / 方案状态。交通标签同步地图，详情检查识别手动交通冲突。
- 备用清单与交通覆盖按方案隔离；继续仅在详情显式保存到浏览器，Planner 不自动保存，刷新详情可恢复。Planner → Detail 保留同一个地图生命周期。
- 保持桌面原底栏 25dvh、原地图 / 右栏比例与折叠断点。手机布局支持横向浏览两排卡及交通编辑，未增加页面横向溢出。

## Boundaries

- 交通修改属于本地估计，没有查询真实路况、班次、路线或票价，不下单。
- 新加入景点的本地空档安排不保证营业时间或真实接驳可行，界面明确提示核对。
- 浏览器验收使用可交互 fallback；没有真实 Mapbox Token，不声明已完成真实底图验收。未提交 Secret 或接入 Provider、AI、Auth、数据库。
- 行程总览仍保留餐宿缺失的建议和下方时间总览项目；移除的是右侧独立餐宿栏，不删除行程内容。

## Route API / Cost Decision

- 本轮没有接入 Directions 或交通时刻服务，没有新增路线 API 请求。页面同步、切换与本地冲突判断无需请求服务商。
- 真实道路几何 / 通行时间需要路线数据；铁路、新干线和班次需另选公共交通服务，不能冒用驾车结果。Mapbox Directions 官方只列 driving、driving-traffic、walking、cycling 四种 profile：[官方说明](https://docs.mapbox.com/api/navigation/directions/)。
- 建议后续使用明确的“更新受影响路线”操作，合并连续编辑，只重算改变的相邻段；按服务商许可复用结果、去重请求，设置用户日限额与总预算，超额停止并保留待核对状态。尚未实现这套服务或费用控制。
- 2026-09-07 查阅 [Mapbox 公开价格](https://www.mapbox.com/pricing)：Directions 每月前 100,000 次请求免费，下一档 $2 / 1,000 次；例如 120,000 次约 $40，仅计 Directions。地图加载、搜索、公共交通服务等另计，实际以账户合同和现行价格为准。
