# Planner 快速设置深入菜单改版

## Status

本地实现；未 commit / push / merge，保留此前未提交修改。

## Implemented

- 保留右上五卡与已认可的二级设计。同行人数继续使用加减按钮，日期继续使用日历。
- 景点、餐饮、住宿的“更多设置”采用原三分区 + 主题点选卡，所有原有字段保留。时间、预算、排队、床型、设施等改为常用选项；每项可恢复“未限定”。
- 手动输入上限按整个详细菜单计算：景点 2 项（必去 / 绝对不去），餐饮 1 项（过敏 / 忌口），住宿 1 项（可选自定义每晚预算）。
- 默认未限定低对比显示，实际选择珊瑚色高亮。小屏选项加大触摸高度，页尾取消与应用按钮固定可达。
- 详细菜单使用局部草稿：切换分区保留，取消 / Esc / 关闭不提交，应用后更新当前旅行偏好；不自动重排或浏览器保存。二级快速点选的既有即时同步行为不变。
- 沿用现有字符串字段与 reducer，不清理原自定义数据；无预设匹配的旧值显示“已保留原填写”，只有用户选择替代值或清除才改变。
- 忌口与无障碍等为偏好记录，不代表实际供应商已确认；未接真实查询或预约。
