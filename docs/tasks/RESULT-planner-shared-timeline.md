## Implemented

- Planner 单日 / 三日时间轴和详情执行轨道共用 `TripTimelineTrack`，使用连续线、上下交错时间卡；手机使用同一套纵向时间卡。
- Planner 时间轴仅展示 `attraction` 景点。过滤仅作用于视图，不删除交通、酒店、餐饮、活动或改变路线。全日城市汇总和其他选单保持原行为。
- 保留点击选中 / 地图联动、双击查看地点，以及三日中切换单日。
- Detail 保留完整安排。时间点圆内显示绿色 ✓（正常）、黄色 !（需确认）、红色 ×（冲突）。颜色由既有本地判断驱动，配合悬停说明和无障碍描述，不冒充实时 AI / 预约验证。
- 保留本地完成状态、时间冲突保护、显式保存和未保存离开保护。适配较矮桌面视口的轨道间距，不改变底栏整体比例。
