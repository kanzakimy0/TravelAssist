## Implemented

- 覆盖上一版三层常展开卡片：恢复共用 25dvh 桌面底栏，移除 Detail 特有加高规则；手机恢复原有底部抽屉高度，不再近全屏加高。
- 所有项目仍在轴线下等距等宽；宽度缩为原来约 2/3（桌面 96–115px，手机 115px）。紧凑高度适配底栏，不按时间长度分配宽度。
- 景点青色、交通浅蓝、餐饮暖杏、住宿淡紫、活动浅粉，类型文字仍保留；状态节点继续使用绿 ✓、黄 !、红 ×，不依赖颜色单独传达含义。
- 提醒 / 预约默认只显示简短按钮，点击向上弹出锚定浮层，不增高底栏；Esc / 外部点击关闭，保留键盘焦点恢复。删除无需预约大加号；无渠道且无已有订单记录的项目不显示预约入口。
- 点击地图景点（含活动）或底部对应卡片，桌面将原上部地图区域分为等宽两栏：左边原 Map，右边景点资料、时间、提醒、标签和调整行程入口。关闭恢复全宽，右侧执行仪表盘不改。
- 手机景点资料使用上部浮层，不强制将狭窄地图再分半；点击底部景点先收起抽屉。新增项目和非景点项目仍可原位进入编辑。
- 共享 Map 组件持续挂载，沿用已有 ResizeObserver；没有创建第二个 Map。景点面板不叠加旧地图快卡。
- Detail 地图工具栏恢复 Planner 同款纵向图层栏，移除上轮横排覆盖。修复平板仪表盘入口遮挡景点关闭按钮。
- 原预约本地记录、取消确认、消息草稿、酒店保护、显式浏览器保存及放弃修改逻辑保留。
