# 等大折叠卡与 Planner / Detail 景点分栏

## Status

本地实现完成，3113 已更新；未提交、推送或合并。本记录覆盖上一版展开浮层宽度与地图 1:1 分栏规则。

## Implemented

- Detail 下方提醒 / 预约折叠卡使用独立向上展开方式，直接测量对应上方行程卡，严格等宽、等高；不改变触发按钮、相邻卡或底栏几何。
- 紧凑卡内保留摘要、快速处理和更多入口，完整说明与预约管理沿用现有二级操作。再次点击、Esc 或外部点击可收起。
- Planner 与 Detail 共用景点详情组件。桌面地图保留原宽度的 2/3，空出的右侧 1/3 显示详情；外部右栏及底栏不调整。
- 两页均支持地图标记与底部景点选中；关闭恢复全宽，始终保留同一个 Map 实例。手机沿用可读的详情浮层，不挤成狭窄三分栏。
- Planner 原有加入 / 替换 / 锁定 / 移出及完整资料入口保留，继续复用权限边界，不在 Planner 新增预约或保存业务。
