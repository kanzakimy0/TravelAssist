## 4. 功能范围规则

- P0 目标是跑通“需求 → 多方案 → 地图行程 → 调整 → 保存”的核心闭环。
- 任何功能进入开发前都应建立独立 GitHub Issue。
- 尚未确认的功能不能因为实现方便而默认进入 P0。
- App 阶段优先复用业务层和数据层，不重复实现一套独立规则。
