本次复用 Phase 1 的逐文件来源，集中审阅实际默认入口、四条间接边和未知副作用的调用路径。execution-policy 的 profile 是下面这些执行路径结论的复用，文件哈希是审阅边界；不是凭缺少关键词将 unknown 改为 false。A 保持基线治理责任；historicalDomainOwner 及其来源保留历史归属，不猜测外围 Owner。

原未证明默认覆盖的 27 文件：23 runtime 保持 OPT_IN（exclusive local stack、identity cleanup、必要时 browser）；TASK084 两个 `.test.py` 和 amendment selftest 为 OPT_IN（冻结本地输入及 temp）；rail selftest 为 DEFERRED（必须显式提供 verified S12 archive，不自动下载）。本次不扩大旧默认强制范围。17 个 `tests/*.browser.mjs` 及其他工具 browser harness 分类 OPT_IN；三个 client-bundle、personal-center replay 和 TASK055/059 aggregate 也保留现有专用入口。aggregate 内 suite/alias 不再次计作独立测试文件。

fixture/helper/config 为 SUPPORT_ONLY，其他外围 operational 候选为 OUT_OF_BASELINE_WITH_REASON，继续保留 unknown 前置及历史 Owner 证据。本任务不把这些候选自动执行，也不要求清零后才能交付。

输入保护：全新独立 checkout；运行前后记录所有 protected paths 的 Git tracked/untracked 状态，并检查 runner/config/lock/inventory 哈希不变；完整图链另外保留原 516 项以上的 byte-bound 输入证明。若发现输入缺失或修改，失败并保留证据，不联网补齐，不 reset/clean/stash 掩盖。
