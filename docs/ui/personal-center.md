## 1. 设计目标

个人中心不是传统后台，也不是数据 Dashboard。

它的核心目标是让用户在进入“自己的空间”后，快速完成三件事：

1. 看见下一次旅行并继续规划。
2. 管理自己已经保存、规划中、完成或收藏的旅行。
3. 在需要时进入长期偏好、同行人和账户管理。

整体体验应保持 TravelAssist 的旅行感：**轻、温暖、让人产生想出发的心情**，同时保持足够清晰的功能层级。

个人中心与主 Planner 的职责边界：

```text
Planner
= 这一次旅行怎么安排

Personal Center
= 我的长期资料、长期偏好、同行人和旅行资产
```

## 2. 最终一级 Information Architecture

个人中心冻结为 5 个一级入口：

```text
Personal Center
│
├── 我的首页 Home
├── 我的旅行 Trips
├── 旅行偏好 Preferences
├── 同行人 Companions
└── 账户 Account
```

### 2.1 我的首页 Home

默认落点。

首页只承担“回来以后下一步做什么”，不承担完整管理功能。

首页显示：

- 下一次旅行 Hero
- 我的旅行摘要
- 通知 / 当前用户入口

首页**不显示**：

- 旅行偏好摘要卡片
- 同行人摘要卡片
- 数据统计 Dashboard
- 大量账户设置

> 注意：旅行偏好和同行人只从首页内容区删除，**左侧一级导航入口必须保留**。

### 2.2 我的旅行 Trips

统一承载用户旅行资产：

```text
我的旅行
├── 即将到来
├── 规划中
├── 已完成
├── 收藏
└── 已归档
```

不再把“历史 / 草稿 / 收藏”做成多个一级导航。

建议语义：

- 草稿 → 规划中
- 历史 → 已完成
- 收藏 → 我的旅行中的筛选项

### 2.3 旅行偏好 Preferences

长期偏好管理中心。

继续采用既有“大项目 → 中项目 → 小项目”的渐进设置原则。

主要领域：

- 旅行风格
- 移动 / 交通
- 景点与活动
- 餐饮
- 住宿
- 预算
- 其他 / 高级设置

这里保存长期偏好；Planner 中的本次旅行临时条件不直接覆盖长期偏好。

### 2.4 同行人 Companions

同行人独立为一级入口。

可管理：

- 本人
- 家人
- 儿童 / 婴儿
- 朋友 / 其他同行人
- 移动能力
- 饮食限制
- 兴趣
- 住宿需求
- 无障碍 / 特殊需求

Planner 创建旅行时只负责“这次和谁一起”，并读取个人中心保存的同行人资料。

### 2.5 账户 Account

账户类低频功能统一收纳：

```text
账户
├── 个人资料 Profile
├── 登录与安全 Security
├── 通知 Notifications
├── 数据与隐私 Privacy & Data
└── 帮助 / Legal
```

删除账户、数据导出等危险或低频操作必须放在深层，不进入旅行主导航。

## 3. Desktop 16:9 总体布局

当前正式基准为 Desktop 16:9。

```text
┌──────────────────────────────────────────────────────────────┐
│ 左侧 Personal Sidebar │        右侧 Personal Home            │
│                       │                               🔔 头像  │
│ Logo                  │ ┌──────────────────────────────────┐ │
│ 用户头像 / 名称        │ │ 下一次旅行 Hero                  │ │
│                       │ │ 京都 · 3天2晚                    │ │
│ 我的首页              │ │ 日期 / 同行 / 交通               │ │
│ 我的旅行              │ │ [继续规划]                      │ │
│ 旅行偏好              │ └──────────────────────────────────┘ │
│ 同行人                │                                      │
│ 账户                  │ 我的旅行                    查看全部 →│
│                       │ ┌────────────────┐ ┌───────────────┐ │
│ [日式水彩风景图保留]   │ │ 主旅行大卡片    │ │ 旅行小卡片 1   │ │
│                       │ │                │ ├───────────────┤ │
│                       │ │                │ │ 旅行小卡片 2   │ │
│                       │ └────────────────┘ └───────────────┘ │
└──────────────────────────────────────────────────────────────┘
```

### 3.1 比例建议

以下为实现参考值，不作为最终像素硬编码：

- Sidebar：约 16%–18% 宽度
- Main：约 82%–84%
- Hero：主内容区顶部约 38%–42% 的首屏高度
- Trips：Hero 下方使用“一大两小”的非对称卡片布局

这种布局比三张等宽旅行卡更有视觉节奏，同时保持用户的当前 / 下一次旅行为第一焦点。

## 4. 左侧 Sidebar 设计冻结

左侧栏是个人中心的稳定导航骨架。

### 必须保留

1. TravelAssist Logo / 品牌标志
2. 用户头像
3. 用户名称
4. 简短同步状态
5. 五个一级入口：
   - 我的首页
   - 我的旅行
   - 旅行偏好
   - 同行人
   - 账户
6. **左侧栏底部日式风景插画**

### 左栏底部插画方向

保留已经确认的视觉：

- 水边 / 湖面
- 朱红鸟居
- 远山
- 少量樱花
- 青海波 / 和纸感纹理

插画只作为 Sidebar 底部视觉收尾，不扩散到整个主内容区。

### 当前项状态

当前导航项采用：

- 浅暖底色
- 朱红 / 珊瑚红文字和图标
- 轻量圆角描边
- 不使用厚重大面积纯红填充

---

## 5. 右侧首页正式布局

### 5.1 顶部全局区

右上仅保留必要的：

- 通知图标
- 当前用户头像
- 下拉入口

不增加额外顶部主导航，避免与左侧一级导航重复。

### 5.2 下一次旅行 Hero

Hero 是首页视觉中心。

信息仅保留：

- `下一次旅行`
- 目的地，例如：京都
- 天数 / 夜数，例如：3天2晚
- 日期
- 同行人数
- 关键移动偏好
- `继续规划` 主 CTA

不在 Hero 中加入：

- 长段文案
- 装饰性日文句子
- 旅行鸡汤文案
- 统计数字
- 复杂行程明细

#### Hero 图片

必须使用**写实摄影 / 高写实照片风格**。

不使用：

- 水彩景点照片
- 卡通景点
- 手绘城市场景
- 过度梦幻 AI 插画质感

可允许轻度暖色调处理，但需保持真实摄影感。

### 5.3 我的旅行

Hero 下方为“我的旅行”。

采用：

```text
左：一个主旅行大卡片
右：两个纵向小卡片
```

主旅行大卡优先显示：

- 即将到来 / 当前正在规划的旅行
- 目的地
- 日期
- 同行人数
- 关键交通偏好

小卡显示更少信息：

- 状态
- 目的地
- 天数
- 日期
- 必要的一项辅助信息

右上提供：`查看全部 →`

进入完整 `我的旅行` 页面。

### 5.4 首页删除项

以下内容**不再出现在个人中心首页正文**：

- 旅行偏好摘要
- 同行人列表 / 同行人卡片

原因：

- 降低首屏信息密度
- 避免首页变成 Dashboard
- 把焦点集中在“下一次旅行”和“我的旅行”

但两者仍保留在左侧一级导航中。

## 6. 背景视觉冻结

最终背景采用已确认的方案 D 延伸方向，但进一步减法。

### 主页面底图

使用：

- 温暖米白 / 象牙白基底
- 非常淡的和纸质感
- 淡粉水彩云雾 / 花瓣感
- 少量青海波纹理
- 非常轻的金粉 / 暖色点缀

### 主页面底图禁止

- **不要放富士山作为大背景**
- 不要大面积鸟居
- 不要寺庙 / 五重塔大背景
- 不要书法 / 中文 / 日文装饰文案
- 不要多组传统日本元素同时抢视觉

原则：

> 日本特色来自“质感、色调和细节”，而不是把所有日本符号同时铺在页面上。

### Sidebar 例外

Sidebar 底部的鸟居风景插画继续保留，因为它被限制在固定区域，不会干扰主内容。

## 7. 色调与对比度

基于最终确认稿，整体视觉强度相较上一版高饱和概念稿**降低约 10%**。

### 目标

- 不是灰色 UI
- 不是低饱和极简到没有旅行感
- 保留开心、温暖和旅行期待
- 避免照片、樱花和红色 CTA 同时过艳

### 推荐方向

- 背景：暖米白
- 主强调：朱红 / 珊瑚红
- 辅助：樱粉 / 淡桃色
- 文字：深灰蓝 / 墨色
- Border：极淡暖粉褐
- 图片：写实、自然暖色，不使用 HDR 过强效果

### 临时语义 Token

具体数值仍可在 Design Token WBS 中统一冻结，当前实现应使用语义名：

```text
--pc-bg-canvas
--pc-bg-sidebar
--pc-bg-card
--pc-accent-primary
--pc-accent-soft
--pc-text-primary
--pc-text-secondary
--pc-border-subtle
--pc-nav-active-bg
--pc-nav-active-text
```

不得因为概念图颜色自行建立另一套互不兼容的全局品牌色系统。

## 8. 摄影与插画使用规则

个人中心采用“两种视觉媒介分工”：

### 真实旅行内容

使用**写实照片**：

- Hero 目的地
- 我的旅行卡片
- 旅行详情缩略图

### 品牌与氛围装饰

使用**轻日式水彩 / 和纸插画**：

- Sidebar 底部固定插画
- 页面角落非常轻的背景纹理
- 小型樱花 / 青海波装饰

### 禁止混用

不要把旅行照片也画成水彩，因为会让“真实旅行资产”和“装饰层”失去层级差异。

---

## 9. 字体与信息层级

### 目的地 / 大标题

可使用具有一点日式书刊感、但清晰易读的 CJK Serif。

### UI / 控件 / 日期

使用清晰 Sans Serif。

推荐结构：

```text
Hero Destination   大号 Serif / 强标题
Section Heading    中号标题
Card Title         中号或半粗
Body               常规 Sans
Meta / Date        小号 Sans
Button              中等权重 Sans
```

避免把大量正文改成书法字体。

## 10. 交互关系

### 首页

```text
个人中心首页
├── 继续规划 → Planner 当前 Trip
├── 我的旅行主卡 → Trip 详情 / 继续编辑
├── 我的旅行小卡 → 对应 Trip
├── 查看全部 → 我的旅行
├── 旅行偏好 → Preferences
├── 同行人 → Companions
└── 账户 → Account
```

### 头像

右上头像与完整头像菜单行为由 WBS 1.22 详细设计。

### Preferences / Companion Contract

个人中心负责长期数据；Planner 通过公开 Contract 消费：

```text
B Preference Contract → A Planner
B Companion Data → Planner Trip Setup
A Trip Plan Contract → B Saved Trips
```

## 11. 首页信息优先级

从高到低：

1. 下一次旅行
2. 继续规划
3. 我的旅行
4. 查看全部旅行
5. 一级导航
6. 通知 / 用户入口

偏好和同行人属于“需要时管理”，不进入首页主信息流。

## 12. Empty State 原则

没有旅行时，首页不能出现大面积空 Dashboard。

建议 Hero 切换为：

```text
下一段旅程，从这里开始
[开始规划]
```

背景仍保持轻日式旅行氛围，但不制造虚假的“下一次旅行”。

我的旅行区显示 1 个轻量 Empty Card 即可。

详细 Loading / Empty / Error 规范归 WBS 1.29。

## 13. Responsive 边界

本设计书冻结 Desktop IA 和 16:9 首页基准。

### Desktop

使用左 Sidebar + 右内容布局。

### Tablet / Mobile

业务含义保持不变，但不要求机械缩放 Desktop：

- Sidebar 可转 Drawer / Bottom Navigation
- Hero 可变为纵向卡片
- 我的旅行“一大两小”可变为纵向列表

详细响应式布局归 WBS 1.29。

## 18. 最终冻结结论

WBS 1.21 的正式结论：

> **TravelAssist 个人中心采用左侧五项一级导航 + 右侧旅行内容主页。视觉采用温暖、轻日式水彩质感的方案 D；日式元素集中在背景质感和 Sidebar 底部插画，真实目的地使用写实摄影。首页只突出“下一次旅行”和“我的旅行”，旅行偏好与同行人仍保留一级导航但不在主页重复展示。整体色彩与对比度在保持旅行愉悦感的前提下，比高饱和概念稿降低约 10%。**
