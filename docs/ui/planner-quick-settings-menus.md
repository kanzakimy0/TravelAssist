# Planner 顶部五卡子菜单重设计

更新：2026-09-06；来源：用户“右侧栏顶部几个选项卡的子菜单重新设计”；Issue #135 / Draft PR #139。

## 范围与视觉

只调整同行人、旅行日期、景点、餐饮、住宿的一级菜单及三类偏好的详细菜单，不修改右栏卡片、推荐方案、Planner 框体或业务状态模型。沿用暖白半透明背景、墨灰文字、珊瑚选中态和单色图标。

- 桌面菜单宽度上限 520px，优先出现在右栏左侧；小屏宽度为视口减去 24px。
- 高度不超过 680px 或视口减去 24px；标题和底部动作保持可见，长内容只在菜单内滚动。
- 继续使用 manual popover top layer，避免动画、模糊和裁切导致弹层离开视口。
- 一级菜单呈现说明、当前选择摘要、分组选项、详细入口及“完成”；不把详细字段重新堆回主卡。

## 同行人

保留成人男性、成人女性、儿童、婴儿四类。总人数摘要加四张独立数量行卡，每行使用原有加减器与 0–20 边界。编辑即时同步当前旅行，“完成”只负责关闭菜单，不伪装成未实现的保存/取消事务。

## 旅行日期

出发与返回并列，支持直接输入以及内嵌单月日历；日历复用现有本地日期工具，支持方向键、Home/End、PageUp/PageDown、Enter，跨月份始终保留可聚焦日期入口。

点击出发后切换到返回端，区间高亮，并展示天数/晚数。日期编辑仍为局部草稿，关闭未应用时恢复原日期；“应用日期区间”才调用现有日期 reducer。保留 1–60 天及固定预约/住宿保护，不自动生成路线。

## 三类偏好

37 个快捷选项按主题拆成两组，已选态使用细边框、浅珊瑚填充和对勾；计数与即时同步说明始终明确。选项、顺序内的标签与原 TripState 字符串键兼容。

详细设置共 54 个原有字段分为三个分区：

| 类别 | 分区一     | 分区二     | 分区三     |
| ---- | ---------- | ---------- | ---------- |
| 景点 | 想去与避开 | 光线与环境 | 节奏与体验 |
| 餐饮 | 时间与预算 | 饮食与照顾 | 用餐体验   |
| 住宿 | 房间与预算 | 设施与照顾 | 入住与移动 |

每个分区显示填写进度。桌面为双列表单，小屏为单列；字段值在分区切换时不丢失，输入即时同步；“返回快速设置”关闭二级菜单并恢复焦点。

这一版保留自由文本值，不把已有任意字符串强制转换成布尔值、枚举或数字，不擅自新增预算单位、儿童年龄、评分权重、持久化或 AI 行为。更多行程设置工作台继续使用原编辑器，重设计只作用于五张快捷卡片。

## 验收

五视口 × 普通/减少动效；每个一级和二级菜单实际检查可见边界、点击命中、输入、Escape 与焦点恢复。遍历全部原详细字段，验证分区切换保值；验证日历键盘、月份切换、日期草稿取消及固定预约保护。截图与报告见 `docs/qa/planner-density/menu-redesign/`。
