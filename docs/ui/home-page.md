# 首页设计

> 状态：v0.4 / **主视觉方案已冻结**  
> 更新日期：2026-09-04  
> WBS：1.4 / 1.13 / 1.16  
> 当前主方案：**日本海边小镇 + 地方电车的沉浸式动态首页**

---

## 1. 页面定位

首页不是传统营销 Landing Page，也不是 OTA 搜索页。

首页只有两个核心职责：

1. 让用户立即开始一次旅行规划。
2. 让用户可以随时从右下角打开 AI 旅行助手。

首页本身不承担功能介绍、价格说明、推荐列表、客户评价或 FAQ 展示。

### 核心体验关键词

- 极简
- 圆润
- 沉浸式
- 明亮
- 安静
- 大留白
- 日本现代旅行气质
- 工具优先
- 少宣传语

---

## 2. 最新主视觉方案

### 2.1 方案结论

首页视觉采用一幅完整、可信、具有空间连续性的日本旅行场景：

```text
日本海边小镇
+ 地方铁路 / 电车
+ 日式住宅与植被近景
+ 海面 / 小岛 / 远山中远景
+ 少量樱花或树影
```

这些元素可以同时存在，但必须属于**同一个真实场景**，不能做成旅游符号拼贴。

### 2.2 允许

- 左侧用町屋 / 木造住宅 / 植被形成近景框景。
- 右侧地方电车及铁路设施成为主要动态主体。
- 中央和中远景保持天空、海面、远山的开放留白。
- 樱花可以作为季节性近景，但只作为画面的一部分。
- 背景整体可以具有电影感和轻度梦幻感，但仍应接近真实旅行摄影。

### 2.3 禁止

不要把以下元素作为互不相关的装饰图标同时堆在页面里：

- 鸟居 icon
- 富士山贴图
- 樱花 icon 雨
- 日本地图轮廓
- 灯笼装饰
- 和风纹样背景墙
- 旅游宣传式大字海报

> 日本感来自场景、构图、光线、色彩和留白，而不是符号数量。

## 3. Desktop 16:9 主构图

Desktop 第一视觉验证画布继续使用 16:9。

```text
┌──────────────────────────────────────────────┐
│ Brand                                  语言   │
│                                              │
│                                              │
│              下一站，去哪里？                │
│              规划行程 · 对话调整             │
│                                              │
│          [ 让我们开始吧  → ]                 │
│          [       登录       ]                 │
│                                              │
│                                      ( AI )  │
└──────────────────────────────────────────────┘
```

### 布局原则

- Hero **居中**。
- Hero 不放在大型玻璃卡片中。
- 背景始终是页面主体。
- UI 只是轻量浮在背景之上的工具层。
- 顶部没有传统大型 Navbar。
- 右下 AI 按钮不抢主 CTA 的视觉焦点。

## 4. Header

### 左上

放置当前项目 canonical brand。

视觉要求：

- 小型
- 清晰
- 不使用大型导航条
- 可有极轻的透明 / 暖白背景帮助复杂画面中的识别
- 不形成显眼的 Card

> 当前概念图中的 `Journi` 仅作为视觉与布局参考。本文**不冻结 TravelAssist → Journi 的品牌重命名**。品牌命名如需调整必须单独决策和建 Task。

### 右上

语言入口保持紧凑：

```text
🌐  简体中文 ⌄
```

要求：

- 视觉轻量
- 不扩展成传统导航菜单
- 如果当前工程尚未实现完整 i18n，本阶段不得因为首页视觉调整引入完整国际化架构

## 5. Hero 文案

### 主标题

```text
下一站，去哪里？
```

这是首页第一视觉焦点。

### 辅助文案

```text
规划行程 · 对话调整
```

只允许一行弱辅助说明。

不要继续追加：

- 个性化行程
- 智能推荐
- 一站式管理
- AI 驱动旅行
- 更多营销式卖点

首页需要保持安静。

---

## 6. Hero 排版

### 主标题

方向：

- 深墨蓝 / 深靛蓝
- 中等到偏轻字重
- 中文标题可以带少量书卷感 / 人文感
- 不做极粗 SaaS 标题
- 不使用夸张渐变字

推荐实现范围：

```css
font-size: clamp(2.5rem, 4.2vw, 4.5rem);
line-height: 1.12;
letter-spacing: 0.02em;
```

最终字体族仍遵循 Design System 和现有工程字体策略，不为了首页单独加入大型字体依赖。

### 辅助文字

推荐视觉：

- 主标题下方 20–28px
- 低于主标题约 50% 的视觉权重
- 灰蓝 / 墨灰
- 字号约 17–22px（Desktop）

---

## 7. 主 CTA

文案：

```text
让我们开始吧  →
```

### 行为

必须进入：

```text
/start
```

不得改回 placeholder。

### 视觉

- 深日本靛蓝 / 墨蓝
- 白色文字
- 胶囊圆角
- 不使用绿色
- 不使用蓝紫霓虹渐变
- 阴影非常轻

Desktop 推荐：

```text
宽：320–390px
高：64–74px
圆角：pill
```

Hover / Focus 只做轻量亮度、边框或阴影变化，不使用明显位移弹跳。

---

## 8. 登录入口

文案：

```text
登录
```

### 层级

登录必须明显弱于主 CTA。

视觉方向：

- 透明 / 暖白半透明
- 极细浅边框
- 胶囊形
- 深墨色文字
- 与主 CTA 大致等宽或略窄

### 行为边界

首页负责登录入口的位置和视觉。

真实登录 / 注册 / Session / Personal Center 属于账户模块，不在首页视觉 Task 中实现。

---

## 9. AI 浮动入口

AI 入口是全局组件。

### 默认状态

右下角固定圆形按钮。

最新主方案要求比旧版更加克制：

- 白色 / 暖白圆形底
- 深靛蓝 AI 图标
- 可以显示非常短的 `AI` Label
- 不再使用大尺寸蓝色发光球
- 阴影轻量

Desktop 推荐：

```text
直径：72–88px
右侧：36–56px
底部：32–48px
```

Mobile 推荐：

```text
直径：56–64px
```

同时考虑 safe-area。

### 展开

点击后继续使用现有 `AIConversationPanel`：

- 右侧浮出或 Mobile Bottom Sheet
- 背景仍可见
- 可以轻微暗化 / blur 背景
- Escape 可关闭
- 关闭后焦点返回 AI Entry

初始内容保持极简：

```text
你好，想去哪里？
```

加一个输入区域即可。

不在首页展示假的路线推荐、三套方案或伪 AI 生成结果。

## 10. 动态背景

### 10.1 技术方案

动态背景技术已冻结为：

```text
WebM
+ MP4 fallback
+ poster static fallback
```

优先使用原生 `<video>`。

禁止为了首页背景引入：

- GIF
- Lottie
- Three.js
- 视频播放器框架
- Framer Motion
- 大型 WebGL 框架

### 10.2 动画语言

最新主方案从“多个旅行画面轮换”进一步收敛为：

> **单一连续场景的慢动态。**

主要运动：

1. 地方电车缓慢驶过。
2. 少量树叶 / 樱花花瓣轻微运动。
3. 海面有非常轻的波动。
4. 光线可有很弱的自然变化。

摄像机：

- 基本固定
- 可以有极慢、几乎不可察觉的推进
- 不快速摇镜
- 不快速 zoom
- 不做强 parallax

建议循环：

```text
20–30 秒
```

目标是用户注意到“画面是活的”，但不会觉得在观看宣传视频。

---

## 11. Poster 与降级

Poster 是正式设计的一部分，不是错误页面。

以下情况必须能只显示 Poster 并保持完整首页体验：

- 首次加载
- 慢网络
- 视频失败
- 浏览器不支持某编码
- `prefers-reduced-motion: reduce`
- 移动端性能降级

动态背景不能成为页面可用性的前提。

---

## 12. 背景亮度与 Overlay

最新参考图方向是：

- 明亮
- 暖
- 空气感
- 低压迫感
- 不把页面洗成纯白

Overlay 只用于保证文字可读。

建议根据具体视频控制在约：

```text
8%–18% 暖白 / 中性浅色覆盖
```

必要时可以对 Hero 中央区域使用非常轻的局部可读性处理，但不要出现明显矩形卡片边界。

禁止：

- 大面积黑色遮罩
- 强 vignette
- 重玻璃层
- 把背景模糊到无法识别旅行场景

---

## 13. 首页色彩

当前首页主方向：

```text
暖白 / 米白
深墨蓝
日本靛蓝
灰蓝
极少量朱红
```

### 角色

- 主标题：深墨蓝
- 主 CTA：深靛蓝
- 主 CTA 文字：白
- 登录：暖白 / 透明
- 次级文字：灰蓝
- AI：暖白底 + 靛蓝图标
- 朱红：只允许 Logo 小点、状态或极小视觉点缀

不使用绿色作为首页品牌主色。

这些规则属于首页已确认视觉方向；全局最终 HEX / OKLCH 仍应通过 Design Token 管理。

---

## 14. 圆润规则

首页的圆润来自按钮和轻量浮动组件，不来自满屏玻璃卡片。

推荐：

```text
主 CTA：pill
登录：pill
AI：circle
语言 Popover（未来）：18–22px
AI Panel：24–28px
```

Hero 本身没有背景 Card，因此不需要 Hero Card 圆角。

---

## 15. 阴影与 Blur

### 阴影

使用非常轻的阴影，只帮助浮动元素从复杂背景中分离。

不使用厚重 SaaS Card shadow。

### Blur

默认首页不需要大面积 blur。

AI 展开后允许：

- 背景轻微 blur
- 背景轻微暗化

但用户仍应辨认出当前旅行场景。

---

## 16. Responsive

至少验证：

```text
1600 × 900
1440 × 900
1024 × 768
390 × 844
```

### Desktop

- 保持 16:9 沉浸构图。
- Hero 位于视觉中心。
- 左上 / 右上 / 右下形成稳定三角工具布局。
- 不产生横向滚动。

### Tablet

- 背景根据关键主体重新裁切。
- Hero 不与电车 / 房屋高对比区域打架。
- AI Panel 不超出 viewport。

### Mobile

不能机械缩小 Desktop。

应：

- 重新设置 `object-position` / background focal point。
- 优先保留天空 / 海面等低干扰区域给文字。
- 标题字号明显下降。
- CTA 宽度接近内容区宽度，但保留左右安全边距。
- AI 按钮缩小并避开 safe-area。
- 允许直接使用 Poster 代替视频。

---

## 17. Accessibility

必须满足：

- 背景视频为装饰内容，不进入 Tab 顺序。
- 主要文字在任何背景帧下保持足够可读性。
- CTA 和登录有清晰 focus-visible。
- AI Button 有 accessible label。
- AI Panel 保留 `aria-expanded` / `aria-controls` 或当前等价实现。
- Escape 可以关闭 AI Panel。
- 关闭后焦点返回 AI Button。
- 支持 `prefers-reduced-motion`。
- 动画不自动播放声音。

---

## 18. Performance

- Poster 优先可见。
- 视频不阻塞 Hero 渲染。
- 背景容器预先确定尺寸，避免 CLS。
- 使用 `object-fit: cover` 或等价布局。
- 控制视频体积。
- 不使用 JS 每帧驱动背景动画。
- Mobile 可以采用 Poster / 更轻媒体资源。

## 19. 首页交互流程

```text
首页
├─ 让我们开始吧
│  └─ /start
├─ 登录
│  └─ Account Flow（由账户模块后续实现）
├─ 语言
│  └─ Language UI / i18n（按独立任务实现）
└─ AI
   └─ 展开 AIConversationPanel
```

游客不应因为尚未登录而无法点击“让我们开始吧”。

## 20. 与 Start Flow 的关系

首页不重复收集完整旅行参数。

点击主 CTA 后进入 `/start`，由 Start Flow 收集：

- 目的地
- 日期 / 天数
- 同行人
- 必要硬限制

首页视觉 Task 不得重写 `StartFlowDraft`。

---

## 21. 与后续 Planner 的设计关系

首页：

> 场景沉浸感优先。

进入规划工作区后：

> 工具效率优先。

后续 Planner 继续使用：

- 大地图
- 右侧镶嵌式设置 / 推荐
- 底部时间轴
- 全局 AI 入口

因此首页与 Planner 的共同语言不是“都使用大照片”，而是：

```text
背景内容是主体
UI 是轻量工具层
圆润但不过度卡片化
AI 始终存在
```

# 最终结论

**P01 主入口首页主设计方案正式确定为：**

> **明亮、极简、圆润的沉浸式日本海边铁路场景。背景中地方电车缓慢驶过；中央只保留“下一站，去哪里？”、主 CTA 与登录；品牌位于左上、语言位于右上、小型 AI 浮动入口位于右下。**

本方案为当前首页 canonical visual direction，后续实现不得无理由退回旧版大型玻璃 Hero、营销卡片或传统导航结构。
