# TravelAssist｜全局说明图标交互规范 v1.3

状态：全局固定规则。来源：用户提供的 v1.3 定稿，并入 TASK-007 / Issue #35。

适用于 Step 1～5、弹窗、Popover、下拉菜单及后续同系列页面；覆盖旧的问号 / 说明图标设计。主题为“日式旅景 × 暖色半透明玻璃界面”。

## 图标与默认状态

- 仅显示小型单色 `?`，字号为相邻标题或标签的约 80%，不得比其更大。例如 20px 对应 16px、16px 对应约 13px。
- 暖灰色辅助层级，hover / focus 提高少量对比度，不用高饱和警示色。
- 不默认展开、自动弹出或常驻显示说明；浮层不占文档流、不改变页面高度。
- 视觉图标小，但可使用不改变排版的透明命中范围，便于触屏操作。

## 交互

- 桌面 Hover / Focus 延迟 150–250ms 显示；实现统一为 **200ms**。
- 鼠标移开延迟 100–150ms 隐藏；实现统一为 **125ms**。
- 基本说明不要求点击。鼠标可以移入浮层继续阅读；离开图标和浮层后关闭。
- Tab 可聚焦，Focus 显示相同说明，Escape 关闭且不移动焦点。
- 在 Modal / 菜单内部，第一次 Escape 仅关闭说明，不连带关闭父容器。
- 手机 / 触屏：第一次点按打开，再次点按或点击空白区域关闭；触屏不会触发 hover 自动打开。
- 同时只显示一个说明浮层；离开页面时取消定时器并清理监听。

## 浮层视觉

- 暖白半透明背景、轻微 blur、小圆角、极浅阴影、深墨蓝正文。
- 宽度约 240–320px，当前目标 288px；小视口预留两侧安全边距。
- 内容简短，优先 1～3 行；避免挡住当前操作控件。
- 优先在标签上方显示，空间不足时翻转到下方，左右限制在视口内。
- 不用大型 Modal 代替简单说明。

## 使用范围与组件约定

统一使用 `src/components/ui/info-popover.tsx`，旧向导导入路径仅作兼容转出。不要在新页面另写 `<details>` 问号或仅靠点击展开的帮助框。

```tsx
import { InfoPopover } from "@/components/ui/info-popover";

<span>
  预算范围
  <InfoPopover
    label="预算范围说明"
    text="预算档位用于平衡住宿、餐饮与体验，可在详情中补充金额和优先项。"
  />
</span>;
```

图标从相邻容器继承字号并缩放到 80%；为每个位置提供能说明上下文的 `label`。Tooltip 内容仅为简短说明，不放输入框、选项或提交按钮。

已接入：Step 1 熟悉度、Step 2 兴趣细分与六条滑轨、兴趣偏好弹窗、Step 3 日期 / 交通 / 预算、Step 4 六阶段说明、Step 5 方案指标。

“细化”、交通详情、预算详情、日历选择等真正的选择 / 输入操作继续使用原 Modal 或 Popover，不能被帮助 Tooltip 替代。

## 验证

- 问号字号 / 标签字号实测为 0.8；默认浮层数量为 0。
- 浏览器验证鼠标进入（无需点击）、移开关闭、Tab / Focus、Escape、弹窗内分层关闭及焦点保持。
- 自动测试覆盖 200ms / 125ms 延迟、短暂悬停取消、浮层可停留、触屏两次点按、外部关闭、定时器清理与视口边界。
- 新页面复用时还需检查自身弹窗层级、边界位置及触屏设备表现。
