## 1. 设计目标

Profile / 账户设置页用于管理用户的个人资料与基础显示设置，不承担完整安全管理，也不承担旅行偏好管理。

核心目标：

1. 让用户快速查看和修改头像、昵称及基础个人资料。
2. 提供语言、地区、时区、货币、单位等国际旅行产品必需的显示设置。
3. 展示已绑定的邮箱与手机号状态，但不在本页直接修改安全凭证。
4. 提供非必要的紧急联系人管理，方便未来旅行中需要紧急联系信息的场景。
5. 保持个人中心方案 D 的温暖旅行感，避免变成传统后台设置页。

边界：

```text
1.24 Profile / Account
= 头像、个人资料、联系方式摘要、基础显示设置、紧急联系人、安全/隐私入口

1.25 Preferences
= 长期旅行偏好

1.28 Security / Data
= 密码、邮箱/手机号绑定与修改、登录方式、登录设备、数据导出、删除账户
```

## 2. 页面位置与 Shell

本页面运行在已经冻结的 `PersonalCenterShell` 中。

左侧固定：

- TravelAssist Logo
- 用户头像 / 昵称
- 我的首页
- 我的旅行
- 旅行偏好
- 同行人
- 账户（当前选中）
- Sidebar 底部日式鸟居水景插画

右上固定：

- 通知
- 当前用户头像
- Avatar Menu

页面切换时 Shell 不变，只替换右侧 Content Area。

## 4. 个人资料 Profile

### 4.1 头像

支持：

- 更换头像
- 删除头像
- 恢复默认头像

头像操作使用轻量 Dialog / Popover，不跳转独立页面。

建议状态：

```text
Avatar
├── Current
├── Uploading
├── Upload Failed
└── Default
```

上传失败时只在头像区显示错误，不阻塞整个页面。

### 4.2 字段

最终字段：

| 字段            | 是否必填 | 说明                           |
| --------------- | -------- | ------------------------------ |
| 昵称            | 是       | 全站显示名称，字段名后显示 `*` |
| 姓名            | 否       | 不显示“可选”文字               |
| 出生日期        | 否       | 不显示“可选”文字               |
| 性别            | 否       | 不显示“可选”文字               |
| 居住国家 / 地区 | 否       | 默认地区建议参考               |
| 常住城市        | 否       | 出发地与本地化参考             |

### 4.3 必填表达规则

页面不使用：

- `（可选）`
- `Optional`
- 大量说明文字标记字段属性

只对必填字段添加星号：

```text
昵称 *
```

星号使用强调色，但不能与 Error 状态混淆。

## 5. 查看态与编辑态

默认进入页面时优先使用查看态，避免整页像后台表单。

### 查看态

```text
昵称
Yuki

姓名
山田由纪

出生日期
1995/08/12

居住地区
日本 · 东京

                         编辑
```

### 编辑态

点击“编辑”后将可编辑字段转换为 Input / Select / Date Picker。

底部出现：

```text
[ 取消 ]   [ 保存修改 ]
```

### 离开未保存状态

若存在未保存修改并尝试切页：

```text
您有尚未保存的修改

[ 放弃修改 ] [ 继续编辑 ]
```

不得静默丢失修改。

## 6. 联系方式 Contact Summary

本页只显示认证联系方式摘要：

```text
联系方式

邮箱
 yu***@gmail.com      已验证

手机
 +81 •••• 1234       已验证
```

### 6.1 不在本页执行的操作

本页不提供：

- 修改邮箱
- 修改手机号
- 修改密码
- 管理第三方登录
- 登录设备管理

这些属于 WBS 1.28。

### 6.2 去重规则

联系方式区域**不再提供“管理登录与安全”按钮**。

页面底部已经存在唯一的 `登录与安全` 入口，因此禁止在联系方式卡中再次出现同功能入口。

这样避免：

```text
联系方式 → 管理登录与安全
底部 → 登录与安全
```

产生重复导航。

## 7. 紧急联系人 Emergency Contact

### 7.1 定位

紧急联系人属于非必要资料。

用途：

- 为未来旅行紧急情况预留联系信息
- 供用户自己记录
- 后续若有安全功能，可在明确授权后使用

第一阶段不得默认向紧急联系人发送任何消息。

### 7.2 空状态

未添加联系人时：

```text
紧急联系人
在您需要帮助时，可保存一位紧急联系人。

[ + 添加紧急联系人 ]
```

该模块不显示红色警告，也不提示“资料未完成”。

### 7.3 添加入口

使用明显但次于主 CTA 的 `+` 添加入口：

```text
+ 添加紧急联系人
```

点击后打开 Dialog / Drawer。

### 7.4 联系人字段

建议第一阶段字段：

| 字段        | 是否必填 |
| ----------- | -------- |
| 姓名        | 是       |
| 与您的关系  | 是       |
| 手机号码    | 是       |
| 国家 / 区号 | 是       |
| 邮箱        | 否       |
| 备注        | 否       |

同样遵循：只有必填字段显示 `*`，不显示“可选”。

### 7.5 已添加状态

```text
紧急联系人

山田太郎
父亲 · +81 90-1234-5678

[ 编辑 ] [ 删除 ]

+ 添加紧急联系人
```

第一阶段至少允许 1 位联系人；实现可预留多联系人能力，但数量上限不在 WBS 1.24 冻结。

### 7.6 删除

删除紧急联系人需要轻量确认：

```text
删除这位紧急联系人？

此操作不会影响您的账户或旅行数据。

[ 取消 ] [ 删除 ]
```

## 8. 基本设置 General Settings

字段：

| 设置        | 示例       |
| ----------- | ---------- |
| 界面语言    | 简体中文   |
| 国家 / 地区 | 日本       |
| 时区        | Asia/Tokyo |
| 默认货币    | JPY ¥      |
| 距离单位    | km         |
| 温度单位    | °C         |
| 时间格式    | 24 小时    |

### 8.1 联动原则

修改国家 / 地区后可以建议：

- 推荐时区
- 推荐默认货币
- 推荐距离单位
- 推荐温度单位

但只能“建议”，不得强制同步覆盖用户的手动设置。

例如允许：

```text
界面语言：简体中文
国家 / 地区：日本
默认货币：JPY
```

## 9. 登录与安全 / 数据与隐私入口

页面底部保留两个清晰的单一入口：

```text
登录与安全                              >
密码、手机、邮箱、登录方式与账户安全

数据与隐私                              >
个人数据、导出与账户相关管理
```

### 9.1 责任边界

`登录与安全` 和 `数据与隐私` 的具体页面及危险操作归 WBS 1.28。

WBS 1.24 只负责入口卡片的：

- 位置
- 标题
- 一句摘要
- 跳转行为

不得在本页直接显示“删除账户”。

## 10. 手机验证码自动注册用户状态

根据 WBS 1.23，未注册手机号验证码登录成功后可自动创建账户。

这类新用户可能只有手机号资料。

Profile 页采用轻提示：

```text
完善您的个人资料
添加昵称、头像和常住地区，让 TravelAssist 更自然地为您准备旅行体验。

[ 完善资料 ]
```

规则：

- 不强制填写完整资料才能继续使用
- 不把空字段全部标红
- 昵称若系统已生成默认值，可允许后续修改
- 联系方式照常显示手机号“已验证”

## 11. 保存与反馈

### 11.1 保存成功

使用页面内轻量反馈：

```text
✓ 已保存
```

约 1–2 秒后弱化 / 消失。

不弹出大型成功 Dialog。

### 11.2 保存失败

显示：

- 字段级错误（如格式问题）
- 页面级轻提示（如网络失败）

不得清空用户已经填写的内容。

## 12. 视觉规范

继续使用 Personal Center 方案 D。

### 背景

- 暖米白 / 象牙白
- 极淡和纸纹理
- 极少量樱粉水彩纹理
- 必要的青海波细节

### 图片与装饰

- Sidebar 底部保留既有鸟居水景插画
- Account 内容区不使用大面积旅行照片
- 不新增富士山、五重塔等大背景
- 不在内容卡中堆叠大量樱花装饰

### 色彩

- 主强调：珊瑚朱红
- 背景：暖米白
- 主文字：墨色 / 深灰蓝
- 次级文字：中性灰
- 边框：极淡暖粉褐
- Verified：独立 Status 色，不使用品牌朱红表示成功

### 卡片

- 大圆角
- 轻边框
- 很浅的阴影
- 不使用厚重 Dashboard 卡片风格

## 16. Codex / 开发实现约束

1. 必须复用已完成的 Personal Center Shell，不重新制作第二套 Sidebar / Top Actions。
2. 当前导航项为“账户”。
3. 不得在联系方式卡和页面底部重复提供“登录与安全”入口。
4. 个人资料字段不显示“可选”；仅必填字段显示 `*`。
5. 当前第一版只有“昵称”确定为个人资料必填字段。
6. 紧急联系人模块必须存在，但属于非必要资料。
7. 紧急联系人空状态必须提供 `+ 添加紧急联系人`。
8. 紧急联系人不得被当作注册或使用 TravelAssist 的前置条件。
9. 账户安全与数据删除的实际功能不得提前塞入本页，归 WBS 1.28。
10. Travel Preferences 不得复制到 Account/Profile 页面。
11. 保存后使用轻量反馈，不弹大型成功窗口。
12. 使用语义 Token，不把概念图颜色直接硬编码为独立品牌系统。

## 18. 最终冻结结论

> **TravelAssist Profile / 账户设置页采用现有 Personal Center Shell，以“个人资料 + 联系方式摘要 + 紧急联系人 + 基本显示设置 + 登录与安全 / 数据与隐私入口”为核心。个人资料不显示“可选”标签，仅必填字段以星号标记；联系方式不重复设置安全入口；紧急联系人作为非必要资料，通过 `+` 按钮渐进添加。安全凭证与删除账户继续下沉到 WBS 1.28。视觉保持温暖米白、轻日式和纸质感与珊瑚朱红强调，不做传统后台 Dashboard。**
