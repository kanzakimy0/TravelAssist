# 1. 本轮最终决策

本轮不是重新发明 Planner，而是把两套方案中各自最好的部分合并：

- **保留现有实现的地图、路线、真实时间数据、设置能力和辅助信息内容；**
- **恢复原设计中更具辨识度的粉白珊瑚色、悬浮式页头、右栏上半卡片结构和底部 Tab 按钮样式；**
- **完全冻结右栏下半“推荐方案”区域，不改变内容结构、卡片顺序、尺寸、选择状态或交互；**
- **底部栏默认严格保持约页面高度四分之一，不允许某个辅助 Tab 自动把页面顶高；**
- **删除右栏中的“其他条件”，所有高级条件只从“更多行程设置”进入；**
- **同行人与旅行日期提升为右栏最突出的两张一级卡片；**
- **地图从页面最顶部开始，左上角只保留可返回首页的 Logo，不保留中部导航菜单；**
- **顶部右侧保留搜索框、通知和头像；地图与顶部搜索区之间用向右渐变完成视觉衔接；**
- **地图左侧保留可开关的小型图层工具栏；地图右上保留“第 N 天 / 3 日 / 全日”范围控件；**
- **底部栏与地图之间不出现突兀白缝，空隙使用从地图向下逐步过渡到面板底色的渐变。**

页面职责继续保持：

```text
地图 = 空间与路线
右栏上半 = 整趟旅行的关键输入
右栏下半 = 方案选择（冻结）
底部栏 = 当前范围内的执行、风险与分析
```

# 3. 页面总布局

## 3.1 桌面布局比例

```text
┌──────────────────────────── Planner Viewport ────────────────────────────┐
│ Logo                  Map / Search overlay                   User actions │
│ ┌──────────────────── 左侧工作区约 75% ──────────────────┐┌ 右栏约 25% ┐│
│ │                                                        ││ 设置上半区  ││
│ │                      地图                              │├─────────────┤│
│ │                                                        ││ 推荐方案    ││
│ │                                                        ││ 原样冻结    ││
│ │  ┌──────────── 底部信息栏：默认高度约 25% ──────────┐ ││             ││
│ │  └──────────────────────────────────────────────────┘ ││             ││
│ └────────────────────────────────────────────────────────┘└─────────────┘│
└──────────────────────────────────────────────────────────────────────────┘
```

主桌面规格：

- 左侧地图工作区：`75%`；
- 右侧栏：`25%`；
- 右栏下半推荐方案：维持现有实现，不因上半改版而压缩；
- 底部栏只覆盖左侧地图工作区，不跨入右栏；
- 页面本身不得产生 document 级纵向滚动；
- 地图底图铺满左侧工作区并延伸到页面顶部；
- 顶部不是一条完整不透明 Header，而是一组悬浮在地图上的控件。

推荐实现变量：

```css
--planner-sidebar-width: clamp(360px, 25vw, 420px);
--planner-workspace-width: calc(100vw - var(--planner-sidebar-width));
--planner-bottom-height: 25dvh;
--planner-bottom-min-height: 200px;
--planner-bottom-max-height: 252px;
```

在主要验收尺寸中：

| Viewport | 默认底栏高度 |
|---|---:|
| 1600×900 | 225px |
| 1440×900 | 225px |
| 1280×800 | 200px |
| 1180×800 | 200px |

不得因为切换到预约、天气、住宿或详细 Tab 而改变该高度。

## 3.2 层级顺序

建议 z-index：

```text
0   Map canvas
10  Map route / marker layer
20  Map controls and bottom transition halo
30  Bottom dock and right sidebar
40  Logo / top search / notification / avatar
50  Map quick card / small popover
60  More Trip Settings workbench
70  Confirmation dialog
```

不得通过给整个页面加一个不透明 Header 遮住地图顶部。

# 4. 最终色彩与视觉语言

## 4.1 色彩方向

恢复原设计的粉白、珊瑚粉、暖灰白与深海军蓝体系；现有冷蓝色只保留给地图路线、交通数据和信息状态，不再作为整个 UI 的主品牌色。

建议 Token：

```css
--planner-accent: #ff4f73;
--planner-accent-strong: #f23f66;
--planner-accent-soft: #fff0f4;
--planner-accent-mist: rgba(255, 226, 235, 0.72);
--planner-surface: rgba(255, 255, 255, 0.92);
--planner-surface-strong: #fffafb;
--planner-page-tint: #fff6f8;
--planner-border: rgba(226, 150, 170, 0.24);
--planner-text: #14254a;
--planner-text-secondary: #64708a;
--planner-route: #1578e8;
--planner-success: #15965f;
--planner-warning: #e88b19;
--planner-danger: #e34b58;
```

若仓库 Design System 已有等价 Token，优先复用，不新增重复变量。

## 4.2 表面与阴影

- 主面板：暖白半透明，`backdrop-filter: blur(10px)`；
- 内部卡片：白色或极淡粉白，不使用大面积纯粉；
- 主面板圆角：`18–22px`；
- 卡片圆角：`12–16px`；
- 阴影应轻：以边界分离为主，不形成后台系统式重叠卡堆；
- 珊瑚色只用于当前选择、主动作、进度和必要强调；
- 地图路线颜色保持交通语义，不强制全部改成粉色。

## 4.3 樱花元素边界

“原有色彩方案”指粉白珊瑚色与温暖氛围，不代表把大面积樱花纹理烘焙进地图。

允许：

- 页面边缘极淡季节性装饰；
- 空白区 3%–6% 透明度的花瓣纹理；
- 当前演示数据使用樱花季标签。

禁止：

- 遮挡道路、地名和路线；
- 影响 Mapbox 地图交互；
- 把真实地图替换为静态樱花插画；
- 让装饰成为实现依赖。

# 5. 顶部区域

## 5.1 左上角

左上只保留：

```text
[TravelAssist Logo]
```

要求：

- Logo 点击返回 `/`；
- 不显示“探索目的地 / AI 行程规划 / 旅行灵感 / 实用工具”等中间导航；
- Logo 区域不使用整条白色 Header；
- Logo 后方可有小范围透明到暖白的局部玻璃底，以保证在复杂地图上可读；
- 不影响地图从页面顶部开始铺设。

## 5.2 右上搜索与用户动作

保留原设计结构：

```text
[搜索景点 · 城市 · 酒店…]   [通知]   [头像] [展开]
```

搜索框：

- 宽 `320–390px`；
- 高 `42–46px`；
- 胶囊圆角；
- 暖白玻璃表面；
- 左侧搜索图标；
- 文本使用次级深蓝灰；
- 聚焦后使用珊瑚色细描边，不使用厚蓝色 ring。

## 5.3 顶部向右渐变

搜索区周边不能出现一块突然盖住地图的白色矩形。应在搜索框左侧开始，向页面右侧逐步过渡到右栏底色。

推荐实现：

```css
.plannerTopFade {
  position: absolute;
  top: 0;
  right: 0;
  width: min(620px, 44vw);
  height: 76px;
  pointer-events: none;
  background: linear-gradient(
    90deg,
    rgba(255, 248, 250, 0) 0%,
    rgba(255, 248, 250, 0.28) 26%,
    rgba(255, 248, 250, 0.72) 62%,
    rgba(255, 247, 249, 0.96) 100%
  );
}
```

视觉要求：

- 左端仍看得到地图；
- 搜索框下方不是独立白色横条；
- 越靠近右栏，背景越接近右栏暖白；
- 渐变层只负责过渡，不拦截地图点击；
- 通知、头像和搜索框位于渐变层上方；
- 渐变边缘不得出现色带或明显分界线。

```text

交通
酒店
美食
更多
```

结构：

- 位于 Logo 下方，不与 Logo 重叠；

- 图标在上、文字在下；

- 底部保留 `» / «` 收起展开按钮。

收起后仅保留一个窄圆角按钮，不移动地图和底栏。

## 6.2 地图右上日期范围

保留垂直范围控件：

```text

3日
全日
```

要求：

- 位于地图工作区右上，不进入右栏；
- 不与顶部搜索框重叠；
- `第 N 天` 支持数字快捷与输入；
- `3日` 使用从当前第 N 天开始的连续窗口；
- `全日` 显示跨城与主干路线；

## 6.3 地图右下控制

继续保留：

- 定位 / 回到路线；
- 放大；
- 缩小；
- 比例尺。

不得因底部栏加入渐变而遮住控制；需要根据底栏高度动态上移。

# 7. 右栏上半最终结构

## 7.1 结构概览

右栏上半使用原版视觉结构，不采用 v0.4 的纵向四行摘要。

```text
┌──────────────────────────────────────┐
│ [同行人]                 [旅行日期]  │  一级突出卡
├────────────┬────────────┬────────────┤
│ 景点偏好   │ 餐饮偏好   │ 住宿偏好   │  二级偏好卡
├───────────────────┬──────────────────┤
│ 更多行程设置      │ 重新生成路线     │
└───────────────────┴──────────────────┘
```

**不得出现“其他条件”。**

## 7.2 同行人与旅行日期

这两张卡是右栏最突出的输入区：

- 2 列等宽；
- 高 `88–104px`；
- 图标尺寸 `28–34px`；
- 标题 `14–15px / 600`；
- 摘要 `13px`；
- 极淡粉或淡紫图标底；
- 卡片边界比下面三张偏好卡更明确；
- 整卡可点击，右侧有箭头；
- hover 时轻微抬升 1–2px；
- 不使用密集表单控件直接铺在卡内。

同行人摘要：

```text
2 位成人 · 1 儿童
成人（男1 · 女1）· 儿童（6岁）
```

旅行日期摘要：

```text
4月10日 – 4月12日
3天2晚
```

## 7.3 景点 / 餐饮 / 住宿偏好

三张卡 3 列等宽，保持原版图标色分工：

- 景点：珊瑚位置图标；
- 餐饮：暖橙餐具图标；
- 住宿：蓝色床图标。

每张只显示：

- 标题；
- 最多 2 条摘要；
- 最多 3 个关键词；
- 点击进入对应偏好编辑层。

示例：

```text
景点偏好
自然风光
· 经典地标
```

```text
餐饮偏好
当地美食
· 甜品
```

```text
住宿偏好
舒适型
· 交通方便
```

不得把三级设置全部塞回卡片。

## 7.4 操作区

左：`更多行程设置`  
右：`重新生成路线`

- 同高 `48–52px`；
- 左按钮暖白 / 浅粉；
- 右按钮珊瑚渐变或实色；
- 修改设置后，右按钮文案改为 `预览 N 项变更`；
- 不允许每次切换 Chip 都自动重算路线；
- 用户确认影响范围后才应用新路线。

# 9. “更多行程设置”打开后的页面

## 9.1 展示方式

点击后打开左侧工作区内的大型设置工作台，不改变右栏宽度，也不覆盖或重排右栏下半推荐方案。

```text
地图工作区                         右栏
┌──────────────────────────────┐   ┌─────────────┐
│ 轻遮罩                       │   │ 设置摘要     │
│  ┌────────────────────────┐  │   ├─────────────┤
│  │ 更多行程设置工作台     │  │   │ 推荐方案冻结 │
│  │ 左分类 + 右内容        │  │   │             │
│  └────────────────────────┘  │   │             │
└──────────────────────────────┘   └─────────────┘
```

推荐尺寸：

- 宽 `760–840px`；
- 高 `min(640px, viewport - 112px)`；
- 左分类 `176–196px`；
- 右内容自适应；
- 底部操作条固定；
- 只对左侧工作区加低透明度遮罩；
- 右栏保持原亮度与位置；
- Esc、右上关闭和点击遮罩可关闭；
- 关闭后焦点回到“更多行程设置”。

## 9.2 顶部与底部

顶部：

```text
更多行程设置
根据您的偏好，定制更合适的旅行方案                     ×
```

底部：

```text
已修改 N 项                         [取消] [保存设置]
```

保存设置后不立即重算路线，右栏改为“有 N 项未规划”。

## 9.3 七个分类

左侧分类固定为：

1. 预算与节奏；
2. 移动与体力；
3. 每日时间；
4. 人流与天气；
5. 摄影与体验；
6. 行李与无障碍；
7. 锁定与预约。

不新增“其他条件”分类。

### 预算与节奏

- 人均日预算范围；
- 预计全程预算；
- 节省 / 舒适 / 高品质档位；
- 很轻松 / 轻松 / 适中 / 紧凑 / 很紧凑；
- 每日主要景点数量；
- 连续高强度日上限；
- 是否优先高性价比；
- 是否允许小幅超预算以明显提升体验。

### 移动与体力

- 电车 / 公交 / 自驾 / 出租车偏好；
- 少换乘；
- 少步行；
- 单日最大步行；
- 单次最大步行；
- 最大换乘数；
- 夜间驾车；
- 山路；
- 停车便利；
- 行李移动约束。

### 每日时间

- 最早出发；
- 最晚回住宿；
- 午餐窗口；
- 晚餐窗口；
- 午休；
- 自由时间；
- 节点间缓冲；
- 固定不可安排时段。

### 人流与天气

- 避开人群 / 热门优先；
- 最大排队时间；
- 早鸟 / 夜间错峰；
- 临时拥挤时允许替换；
- 雨、雪、高温、强风阈值；
- 户外活动自动降级；
- 船班、缆车和山区风险策略。

### 摄影与体验

- 摄影优先；
- 日出、日落、夜景；
- Golden Hour；
- 拍照额外停留；
- 是否允许为光线调整顺序；
- 本地体验比例；
- 自由探索比例；
- 经典景点与小众景点平衡。

### 行李与无障碍

- 行李件数与尺寸；
- 寄存；
- 酒店转运；
- 婴儿车；
- 电梯；
- 无障碍需求；
- 儿童设施；
- 休息与医疗要求。

### 锁定与预约

- 保留核心景点；
- 不修改固定预约；
- 锁定某天；
- 锁定时间；

# 10. 底部栏外形与地图渐变

底部栏默认高度为左侧 Planner Viewport 的约四分之一：

```text

```

不得在本轮改名为“交通 / 预约 / 天气 / 吃住 / 体检”。

样式：

- 图标 + 文字横向组合；
- 等宽分段；
- 分段间细竖线；
- 激活项极淡粉背景；
- 激活文字和图标为珊瑚色；
- 底部 2–3px 珊瑚色指示线；
- 非激活项为深蓝灰；
- 不改成六个独立大胶囊。

`详细` Tab 的内容可以是“行程体检”，但 Tab 文案仍保持 `详细`。

## 10.3 地图向下渐变

底部栏上方与周边的空隙不得是纯白断层。地图应在接近面板时逐步过渡到暖粉白面板底色。

推荐结构：

```text
地图可读区域
↓ 透明
↓ 轻微暖粉雾化
↓ 暖白玻璃过渡
底部栏
```

推荐实现：

```css
.plannerBottomFade {
  position: absolute;
  left: 0;
  right: 0;
  bottom: calc(var(--planner-bottom-height) - 1px);
  height: 44px;
  pointer-events: none;
  background: linear-gradient(
    180deg,
    rgba(255, 247, 249, 0) 0%,
    rgba(255, 247, 249, 0.18) 28%,
    rgba(255, 247, 249, 0.58) 68%,
    rgba(255, 248, 250, 0.94) 100%
  );
  backdrop-filter: blur(2px);
}
```

面板左右外缘可增加小范围径向过渡，避免形成硬矩形：

```css
background:
  linear-gradient(...),
  radial-gradient(circle at left bottom, rgba(255, 239, 245, .42), transparent 62%),
  radial-gradient(circle at right bottom, rgba(255, 239, 245, .42), transparent 62%);
```

约束：

- 渐变高度 `36–48px`；
- blur 不超过 `4px`；
- 不遮蔽临近底栏的关键 Pin；
- 地图控制需要上移到渐变上方；
- 渐变层不拦截点击；
- 面板本身仍有明确圆角和边界；
- 不使用一条纯粉色横带。
