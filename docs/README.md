# TravelAssist 文档索引

本目录用于保存产品、UI/UX、技术、AI、数据与开发计划文档。

## 建议目录

```text
docs/
├─ product/        # 产品定位、核心流程、功能边界
├─ ui/             # 页面、组件、交互、视觉规范
├─ preferences/    # 偏好系统大/中/小项目及规则
├─ ai/             # AI 对话、行程生成、推荐逻辑
├─ architecture/   # 前后端、数据结构、API、状态管理
├─ planning/       # WBS、阶段计划、人员分工
└─ decisions/      # 已冻结的重要设计决定
```

## 文档规则

- 优先使用 Markdown。
- 一个主题尽量一个文件。
- 已经确定的规则标注为“已冻结”。
- 尚未决定的问题放在 `未确定事项` 小节。
- 修改设计时同步更新文档，不只保留在聊天记录里。
