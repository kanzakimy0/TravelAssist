# TravelAssist

AI 辅助旅行规划 Web / App 项目。

## 项目目标

TravelAssist 以“地图 + 行程时间轴 + AI 对话 + 详细偏好设置”为核心，帮助用户从模糊旅行需求快速生成可执行的多方案行程，并能继续细调交通、住宿、餐饮、景点与同行人偏好。

## 当前产品方向

- 先开发 Web 版，再扩展手机 App。
- 首页保持极简，主要入口为“让我们开始吧”、登录以及右下角 AI 对话入口。
- 行程主页面采用约 3:1 的地图 / 设置布局，参考 Komoot 的沉浸式地图体验。
- 地图中展示每日路线、景点、交通方式、推荐住宿区域与餐饮区域。
- 底部使用时间轴展示景点、交通、餐饮等连续行程。
- 右侧采用镶嵌式设置面板，上方为详细设置，下方为推荐方案概览。
- 偏好系统采用“大项目 → 中项目 → 小项目”三级结构，并支持快速设置。
- 同行人信息优先设置，用于判断亲子游、情侣、朋友、家庭等旅行倾向。
- AI 负责理解自然语言需求、生成候选方案、解释推荐原因，并协助调整行程。

## 开发协作

项目按两人协作设计：

- A：约 70%，负责核心架构、主要功能、集成与发布。
- B：约 30%，负责可独立拆分的页面、组件、测试、数据整理及临时接手任务。
- GitHub Issue：每项开发工作的唯一任务来源。
- 功能开发：从 `develop` 创建 `feature/*` 分支。
- Bug 修复：使用 `fix/*` 分支。
- 所有功能通过 Pull Request 合并回 `develop`。
- 稳定版本再从 `develop` 合并到 `main`。

详细规范见 [CONTRIBUTING.md](CONTRIBUTING.md)。

## 分支结构

```text
main                 # 稳定 / 可发布版本
develop              # 日常集成
feature/a-*           # A 的功能分支
feature/b-*           # B 的功能分支
fix/*                 # Bug 修复
```
